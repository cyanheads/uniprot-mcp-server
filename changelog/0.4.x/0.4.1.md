# 0.4.1 — 2026-11-17

## Added

- **`uniprot_get_entry` sections** `sites` (active and binding sites, with `ligand` and `ligandPart`), `topology`, `processing`, `comments` (PTM, pathway, subunit, tissue specificity, other free-text types, and DISEASE notes that name no disease), `mutagenesis`, and `interactions` (IntAct partners) ([#35](https://github.com/cyanheads/uniprot-mcp-server/issues/35)). The last two come back only when `sections` or `fields` names them.
- **`uniprot_get_entry` fields** `ecNumbers`, `alternativeNames`, `ensemblGenes`, `disease[].note`, and `goTerms[].evidenceType` ([#35](https://github.com/cyanheads/uniprot-mcp-server/issues/35)).
- **`uniprot_get_entry` `accessions`** accepts up to 500: repeats collapse, the first 20 distinct are fetched, and the rest return in order in `deferredAccessions` for the next call ([#41](https://github.com/cyanheads/uniprot-mcp-server/issues/41)).
- **`UNIPROT_CLAMP_LIMITS`** (default `true`) serves over-the-cap inputs and logs and counts each one; `false` restores 0.4.0's strict maximums and rejections ([#41](https://github.com/cyanheads/uniprot-mcp-server/issues/41)).

## Changed

- **`uniprot_get_entry` default record** requests more annotation types and cross-reference databases, so records are larger: P29972 (24,574 bytes against the 24,000-byte budget) now returns a section outline on its own, where 0.4.0 inlined it ([#34](https://github.com/cyanheads/uniprot-mcp-server/issues/34), [#35](https://github.com/cyanheads/uniprot-mcp-server/issues/35)).
- **`uniprot_get_entry` batches** measure each record alone, as a one-accession call would: a batch returns `kind: "full"` with every fitting record in `succeeded[]` and the oversized ones in `outlinedEntries`. `outlinedEntries[].bytes` now reports that one-accession size across both output surfaces, where it measured the record's JSON alone ([#40](https://github.com/cyanheads/uniprot-mcp-server/issues/40)).
- **`size`** (search, proteome) above 500 is served at 500 with a notice, and **`section_limit`** has no maximum; `tools/list` advertises none for either ([#41](https://github.com/cyanheads/uniprot-mcp-server/issues/41)).
- **`uniprot_get_entry` `fields`** that is whitespace-only now returns the default record; 0.4.0 returned only the identity fields ([#34](https://github.com/cyanheads/uniprot-mcp-server/issues/34)).
- **Absent-sections trailer** says a section can be missing because `fields` left it out.
- **Every `UNIPROT_*` variable** is listed in `server.json`, `manifest.json`, and the plugin manifests ([#41](https://github.com/cyanheads/uniprot-mcp-server/issues/41)).
- **`uniprot_protein_dossier`** prompt and the `uniprot-guide` skill (1.1) name the new sections and `deferredAccessions`.

## Fixed

- **`uniprot_get_entry` and `uniprot_search_proteins` `fields`** names the tool cannot return are left out of the UniProt request and listed in the new `ignoredFields` with a notice; 0.4.0 dropped them silently or failed `invalid_fields`. Names the entry renders (`ft_act_site`, `cc_ptm`, `ec`, any `xref_<database>`) now fill their sections instead of being fetched and dropped ([#34](https://github.com/cyanheads/uniprot-mcp-server/issues/34)).
- **`keywordid`** no longer fails output validation ([#34](https://github.com/cyanheads/uniprot-mcp-server/issues/34)).
- **`genes` and `geneNames`** include ordered-locus and ORF names, and **`domains`** include DNA-binding regions and coiled coils, inserted in UniProt order so later array positions shift ([#34](https://github.com/cyanheads/uniprot-mcp-server/issues/34)).
- **Mutagenesis and natural-variant rows** keep every substituted residue (`variation: "A,P"`) ([#35](https://github.com/cyanheads/uniprot-mcp-server/issues/35)).
- **`functionSnippet`** (search, proteome) is whole sentences within 250 characters; a first sentence over 400 is cut at a word and ends with `…`. A sentence ending after a gene symbol (`IGF1R.`) is recognized, and evidence-tag stripping runs in linear time ([#36](https://github.com/cyanheads/uniprot-mcp-server/issues/36)).
- **`organism.mnemonic`** is populated; it was declared but never filled.
- **`.mcpb` bundle** no longer ships a dependency's `AGENTS.md` under `node_modules`.
