# 0.3.0 — 2026-10-22

## Changed

- **Search and proteome cursors** are now bound to the tool and exact query; legacy raw cursors are rejected, so restart pagination after upgrading ([#25](https://github.com/cyanheads/uniprot-mcp-server/issues/25)).
- **`uniprot_get_entry` overflow** measures the complete inline result across both surfaces against 24,000 UTF-8 bytes; oversized batches return ordered `outlinedEntries` and every failure for individual accession re-calls ([#23](https://github.com/cyanheads/uniprot-mcp-server/issues/23)).

## Fixed

- **Entry rendering** includes every returned list item and cross-reference ID, including explicit section re-calls and windows ([#27](https://github.com/cyanheads/uniprot-mcp-server/issues/27)).
- **Completed mapping continuations** rejected with HTTP 400 return a fixed safe `invalid_continuation` message and restart guidance ([#28](https://github.com/cyanheads/uniprot-mcp-server/issues/28)).
- **Taxonomy alternative names** render completely in their original order, preserving Markdown-sensitive values ([#29](https://github.com/cyanheads/uniprot-mcp-server/issues/29)).
