# 0.1.1 — 2026-06-25

Initial release. Protein-first research over the keyless UniProt REST API (`rest.uniprot.org`), spanning the UniProtKB, ID Mapping, Proteomes, and Taxonomy collections, distributed as `@cyanheads/uniprot-mcp-server`.

## Added

- **`uniprot_search_proteins`** — UniProtKB discovery search by plain text or Lucene field query, with the reviewed (Swiss-Prot) filter foregrounded, optional server-side facet counts, and forward cursor pagination.
- **`uniprot_get_entry`** — batch fetch of up to 20 curated entries by accession with per-accession `succeeded[]` / `failed[]` rows; an oversized single record returns a section outline (`kind: "outline"`) for re-call with `sections`.
- **`uniprot_map_ids`** — cross-database identifier translation via UniProt's async ID-mapping service (Gene_Name, Ensembl, RefSeq, ChEMBL, PDB, GeneID ↔ UniProtKB); polls within a budget and returns a resumable ticket (`status: "running"`) on overflow.
- **`uniprot_get_proteome`** — reference proteome by UPID or NCBI taxon ID with protein count, BUSCO completeness, and genome assembly metadata, plus an opt-in capped page of the proteins.
- **`uniprot_get_taxonomy`** — taxonomy record by NCBI taxon ID or scientific name, with rank, parent, full lineage, and optional immediate children.
- **`uniprot_get_sequence`** — canonical amino-acid FASTA for an accession, with parsed header, length, and optional isoform sequences.
- **`uniprot://entry/{accession}`** and **`uniprot://taxonomy/{taxonId}`** resources — by-ID mirrors of `uniprot_get_entry` and `uniprot_get_taxonomy`.
- **`uniprot_protein_dossier`** prompt — guided protein-research workflow chaining identifier resolution, the curated entry, disease and variants, and outbound cross-references for structure, citations, and bioactivity.
- **`UniProtService`** — single `fetch` client over all four UniProt REST collections, with retry/backoff and HTML-error-page detection.
- **`UNIPROT_*` configuration** — optional `UNIPROT_BASE_URL`, `UNIPROT_TIMEOUT_MS`, `UNIPROT_ID_MAPPING_BUDGET_MS`, and `UNIPROT_DEFAULT_PAGE_SIZE` overrides. Keyless — no API key required.
- Built on [`@cyanheads/mcp-ts-core`](https://www.npmjs.com/package/@cyanheads/mcp-ts-core) — STDIO and Streamable HTTP transports, declarative definitions, unified error handling, structured logging, and optional OpenTelemetry.

## Changed

- **Package identity** — npm name scoped to `@cyanheads/uniprot-mcp-server` across the install surfaces (README, plugin manifests, `server.json` package identifiers); `runtimeHint` set to `bun`. Tightened the package, plugin, and OCI image descriptions and expanded the npm keyword set; added `bugs`, `homepage`, `funding`, and `repository` metadata.
