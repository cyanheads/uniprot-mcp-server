# 0.2.3 — 2026-08-30

## Changed

- **`uniprot_map_ids` returns one completed results page per call** and exposes a distinct `continuation` for the next page, separate from a running-job `ticket` ([#14](https://github.com/cyanheads/uniprot-mcp-server/issues/14)).

## Fixed

- **`unmappedIds` preserves UniProt `failedIds`** instead of inferring failures from normalized mapping rows ([#13](https://github.com/cyanheads/uniprot-mcp-server/issues/13)).
- **Finished mapping status probes do not follow UniProt's results redirect**, leaving result retrieval to the completed-page path ([#15](https://github.com/cyanheads/uniprot-mcp-server/issues/15)).

## Dependencies

- `@biomejs/biome` `2.5.9` → `2.5.11`
- `@types/node` `^26.2.0` → `^26.4.0`
