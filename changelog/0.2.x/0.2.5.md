# 0.2.5 — 2026-10-08

## Changed

- **Tool error results close with `(reason <reason> · request <id>)`** instead of `(reason <reason>)`, and tool and resource error `data` carries `requestId` (cyanheads/mcp-ts-core 0.13.10). A test pinning the old text byte-exact will move.
- **`uniprot_get_entry` with a `sections` name the record lacks** now fails as `-32602` naming the unmatched and available keys (`data.unmatched`, `data.available`), where an unknown name used to be dropped silently (cyanheads/mcp-ts-core 0.13.8).
- **A numeric string sent for a numeric field is repaired before validation**, so `uniprot_search_proteins` `size: "5"` succeeds (cyanheads/mcp-ts-core 0.13.14).
- **Declared recovery hints come from each tool's `errors[]` contract** instead of explicit `ctx.recoveryFor` forwards. Callers receive the same `recovery.hint` and `Recovery:` line as before.
- **The MCP Registry entries in `server.json` run the published bin directly**: `runtimeHint` `bun` → `npx`, the `run start:stdio` / `run start:http` package arguments are removed, and the streamable-HTTP entry sets `MCP_TRANSPORT_TYPE` to `http`.
- **The Docker image installs production dependencies in a `deps` stage pinned to the build platform**, cross-installing for the target architecture; it installs the OpenTelemetry peers through `scripts/install-otel.ts`, prunes musl-only native bindings (`scripts/prune-musl-packages.ts`), and moves to Bun 1.4.2.
- **MCP SDK `^2.0.0` → `^2.2.0` through the framework**: on protocol revision 2026-07-28 a POST without `MCP-Protocol-Version` is refused `400`/`-32020`, a JSON-RPC batch over 100 messages is refused, and on stdio, stdin EOF aborts in-flight requests (cyanheads/mcp-ts-core 0.13.9).
- **Ignore rules**: `.gitignore` and `.dockerignore` cover every `.env*` file (`.env.example`, `.env.template`, `.env.sample` stay tracked), `.dockerignore` also excludes the registry token files, `.mcpbignore` excludes `docs/idea.md`, `logs/`, `.cache/`, `coverage/`, and `tests/` from the bundle, and `package.json` `files` excludes `dist/*.mcpb` from the npm tarball.
- **`.env.example` and the README environment table** document the framework's newer opt-in variables.
- **CodeQL runs one job per language** (`actions`, `javascript-typescript`), each uploading under `/language:<language>`.
- **Plugin manifests, `manifest.json`, and `server.json`** word the description with a colon in place of the em dash.
- **Framework scripts and skills resynced** to 0.13.14, with a `lint` block added to `devcheck.config.json`; `CLAUDE.md` and `AGENTS.md` follow the framework template.
